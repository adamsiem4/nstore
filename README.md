# nstore

A fullstack store built with Next.js (App Router), React 19, Tailwind CSS 4.

Where it's going:

- **Storefront** — light-themed landing page, product listing, product detail pages.
- **Cart & checkout** — server actions for cart mutations, Stripe for payment.
- **Catalog** — products in Postgres, currently a hardcoded array in `app/page.tsx`.
- **Admin** — create/edit products, view orders.

Current state: landing page only.

```bash
bun install
bun dev
```
