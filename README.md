# nstore

A light-themed storefront built with Next.js 16, React 19, Tailwind CSS 4,
and TypeScript.

## Current features

- Landing page with a large rounded banner and featured products
- Product catalog and dynamic product detail pages
- JSON product endpoint at `GET /api/products`
- Shared storefront header, footer, product card, and product grid
- In-memory product data behind an async query module
